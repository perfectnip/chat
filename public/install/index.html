Install the app on your desktop or phone

Mac

macOS desktop app

A lightweight native wrapper around the web app — chat from your Mac without a browser tab.
v1.6-desktop ~2 MB macOS 12+
Download .app
How to install
  1. Click Download .app — it downloads a .zip.
  2. Open the .zip to extract JimmyQrg Chat.app.
  3. Drag JimmyQrg Chat.app into your Applications folder.
  4. The first time you open it, right-click the app and choose Open (then Open again in the dialog) to allow it.

Chromebook

ChromeOS app (Android APK)

Install the Android app on Chromebooks that support Android apps. This APK is also available for Android phones.
v1.7 ChromeOS with Play Store Android 7.0+
Download Chromebook APK
How to install
  1. Download the APK and open the Chromebook's Files app.
  2. Open the APK on a Chromebook with Android app support and APK sideloading enabled.
  3. Some school-managed Chromebooks block APK sideloading. In that case, open jchat.fly.dev in Chrome and choose Install page as app from the browser menu.

Windows

Windows 10 and 11 desktop app

Run JimmyQrg Chat in a dedicated desktop window. The installer creates Start menu and desktop shortcuts.
v1.7 Windows 10+ x64
Download Windows app
How to install
  1. Download and open the .msixbundle file.
  2. Follow the installer prompts. Windows may show a SmartScreen warning because this app is not code-signed.
  3. Launch JimmyQrg Chat from the Start menu.

Android

Phone app (sideload APK)

The Android app for your phone. Sideloaded as an APK — no Play Store required.
v1.7 ~28 MB Android 7.0+
Download .apk
How to install
  1. Tap Download .apk. Your browser saves the file.
  2. Open your Downloads (or the notification bar) and tap the APK.
  3. If Android asks to allow "install unknown apps", tap Settings in the dialog.
  4. Toggle Allow from this source on for the browser you used.
  5. Tap the APK again and confirm Install.
Huawei / HarmonyOS: the toggle lives under Settings → Apps & services → App management → [your browser] → Install unknown apps. Tap Settings in the blocked dialog to jump straight there.
